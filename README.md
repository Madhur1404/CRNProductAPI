# CRNProductAPI

RESTful Product CRUD API developed using .NET 8, ASP.NET Core Web API,
Entity Framework Core and SQL Server.

## Features
- Create Product
- Get All Products
- Get Product By ID
- Update Product
- Delete Product
- Swagger API Documentation

## Tech Stack
- .NET 8
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger

## API Endpoints

GET    /api/products
GET    /api/products/{id}
POST   /api/products
PUT    /api/products/{id}
DELETE /api/products/{id}
